# Sport Test Automator

This project contains automated tests for monitoring sports betting websites, specifically focusing on animation detection across different sports events.

## Features

- Automated testing of multiple sports betting platforms
- Animation detection for live events
- Support for multiple sports (Football, Tennis, Cricket)
- Comprehensive test reporting
- Email notifications for test results

## Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm (comes with Node.js)
- Python 3.8+ (for email notifications)

### Installation

1. Clone the repository:
   ```sh
   git clone git@gitlab.com:d-jazz-group/sport-test-automator-main.git
   cd sport-test-automator-main
   ```

2. Install dependencies:
   ```sh
   npm install
   npx playwright install
   pip install -r requirements.txt
   ```

## Running Tests

### Run All Tests
```sh
npx playwright test
```

### Run Specific Test
```sh
npx playwright test tests/tests/PlanetSportbet-football.spec.ts
```

### Run with UI Mode (Interactive)
```sh
npx playwright test --ui
```

## Test Structure

- `tests/tests/` - Contains all test files
  - `Planetsport-automation.spec.ts` - Main test suite
  - `PlanetSportbet-football.spec.ts` - Football-specific tests
  - `planetsportbet-tennis.spec.ts` - Tennis-specific tests
  - `planetsportbet-cricket.spec.ts` - Cricket-specific tests
  - `starsports-all-InPlay-automationtest.spec.ts` - StarSports specific tests
- `tests/inPlayJourney.spec.ts` - End-to-end journey test

## GitLab CI/CD

This project uses GitLab CI/CD for automated testing. The pipeline includes:

- Parallel test execution
- Test result artifacts
- Email notifications

### Pipeline Configuration

- Configure email settings in GitLab CI/CD variables:
  - `SMTP_USER` - Your email address
  - `SMTP_PASSWORD` - Your email app password
  - `RECIPIENTS` - Comma-separated list of recipient emails
