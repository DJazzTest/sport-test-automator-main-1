║           IMPORTANT FOR MAC USERS                             ║
╚══════════════════════════════════════════════════════════════╝

When running scripts on Mac, you MUST use ./ before the script name!

✅ CORRECT:
   ./run-f1-test.sh
   ./run-tests.sh
   ./setup.sh

❌ WRONG (won't work):
   run-f1-test.sh
   run-tests.sh
   setup.sh

═══════════════════════════════════════════════════════════════

QUICK COMMANDS FOR MAC:

First time setup:
  cd ~/Desktop/sport-test-automator-main-1
  ./setup.sh

Run all tests:
  cd ~/Desktop/sport-test-automator-main-1
  ./run-tests.sh

Run F1 test only:
  cd ~/Desktop/sport-test-automator-main-1
  ./run-f1-test.sh

Choose a test from menu:
  cd ~/Desktop/sport-test-automator-main-1
  ./run-single-test.sh
